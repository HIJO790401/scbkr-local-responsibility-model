SCBKR 支援中心 / Support

SCBKR FREE 是 Windows 10/11 x64 的本地責任規則作業系統。它不內建模型或 API 金鑰。

SCBKR FREE is a local responsibility-rule operating system for Windows 10/11 x64. It does not bundle a model or API key.

開始使用 / Getting started

  1. 開啟 SCBKR 並確認本機 Runtime 顯示運行中。
  2. 在模型設定連接 LM Studio、Ollama 或 OpenAI-compatible 端點。
  3. 執行模型連線測試。
  4. 一般聊天，或要求模型把需求整理成 S/C/B/K/R 規則確認單。
  5. 檢查並修改確認單；只有使用者可以簽名及確認入庫。

常見狀態 / Common states

  • 模型未連線：檢查端點網址、模型名稱與服務是否已啟動。
  • 只能保留草稿：模型輸出未通過五維格式或 Kernel Validator，系統不會用模板偽裝完成。
  • 規則未命中：確認規則已由使用者簽名、完成入庫且狀態為啟用。
  • Token 尚無節省比例：必須完成可比較的 provider usage A/B 計量後，系統才會標示已驗證比例。

問題回報 / Report an issue

請到 GitHub Issues 回報可重現步驟、Windows 版本與 SCBKR 版本。不要公開張貼 API 金鑰、密碼、身分文件或私人規則內容。

Use GitHub Issues and include reproduction steps, Windows version, and SCBKR version. Never publish API keys, passwords, identity documents, or private rule content.
