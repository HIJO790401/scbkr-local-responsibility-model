SCBKR 隱私權政策 / Privacy Policy

生效日 / Effective date: 2026-08-20

本地優先 / Local first

SCBKR FREE 預設把規則草稿、使用者簽名、回放紀錄、模型設定與四庫資料保存在使用者自己的 Windows 裝置。SCBKR 專案目前不提供開發者營運的帳號雲端、廣告追蹤或預設遙測服務。

SCBKR FREE stores rule drafts, user signatures, replay records, model settings, and four-store data on the user's Windows device by default. The project currently provides no developer-operated account cloud, advertising tracker, or default telemetry service.

外部模型與工具 / External models and tools

只有在使用者自行設定 LM Studio、Ollama 或 OpenAI-compatible 端點後，SCBKR 才會把完成工作所需的內容傳送到該端點。傳送範圍依本次任務與最小 current rule package 決定。外部服務的資料處理另受該服務自己的條款與隱私政策約束。

SCBKR sends task content only after the user configures an LM Studio, Ollama, or OpenAI-compatible endpoint. The request is limited to the current task and its minimal current rule package. Any external service processes data under its own terms and privacy policy.

模型權限 / Model authority

模型只能協助草擬與說明。模型不能替使用者簽名、正式入庫、啟用規則、付款、發布或執行高風險工具動作。

The model may draft and explain. It cannot sign for the user, perform final storage, activate rules, pay, publish, or execute high-risk tool actions.

保留與刪除 / Retention and deletion

資料會保留在本機，直到使用者在產品內修改或刪除，或自行移除 SCBKR 的本機應用程式資料。解除安裝前，使用者應先匯出需要保留的規則與紀錄。

Data remains local until the user modifies or deletes it in the product, or removes SCBKR application data from the device. Users should export any rules or records they need before uninstalling.

網路與手機連線 / Network and mobile connection

本機 API 預設只綁定 127.0.0.1。區域網路手機連線預設關閉；使用者主動啟用時必須設定配對權杖，並自行管理所在網路的安全。

The local API binds to 127.0.0.1 by default. LAN mobile access is disabled by default; users who enable it must configure a pairing token and are responsible for their local network security.

支援 / Support

隱私或產品問題可透過 SCBKR GitHub Issues 提交。請勿在公開 Issue 張貼密碼、API 金鑰、身分文件或私人規則內容。

Privacy and product questions can be submitted through SCBKR GitHub Issues. Do not post passwords, API keys, identity documents, or private rule content in a public issue.
